# Web Search

Access external documentation and verify API signatures using available web tools.

## Guidelines

1. **Be Specific:** Include library names, exact version numbers, and error codes in search queries.
2. **Official Docs First:** Prioritize official documentation, GitHub issues, and changelogs over blogs.
3. **Extract Relevant Facts:** Quote exact code signatures and constraints rather than dumping broad page text.
