# Daily Memory Logs

This folder holds short-term, rolling daily logs (`YYYY-MM-DD.md`) recording task progress, debugging insights, and test execution outcomes across sessions.

- **Format:** `YYYY-MM-DD.md` (e.g. `2026-08-18.md`)
- **Lifecycle:** Generated during work, referenced when resuming tasks, and compacted into `context.md` upon milestone completion.
- **Rules:** Follow `.agents/rules/memory.md`.
