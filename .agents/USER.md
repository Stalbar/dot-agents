# Developer Profile & Preferences

## 1. Developer Context
- **Name / Handle:** User
- **Role:** Lead Developer / Architect
- **Language / Locale:** English (en-US)

## 2. Communication & Interaction Style
- **Tone:** Direct, concise, technical. No filler or hype language.
- **Output:** Code and concrete facts first. Keep explanations under 3 lines unless a full report was explicitly requested.
- **Questions:** Ask one question at a time; include the recommended default.

## 3. Tooling & Workflow Preferences
- **Discipline:** Enforce YAGNI (Ponytail style), standard library first, shortest working diffs.
- **Testing:** Verify all changes with actual test runs before claiming completion.
- **Review Strictness:** High. Flag unrequested abstractions and premature optimizations.
