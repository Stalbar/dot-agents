# /update-context

Refresh `.agents/context.md` from recent work.

Execution block:

- `python .agents/commands/scripts/update-context.py`

Then review the file and update its sections based on the latest `docs/`
artifacts and git log: Recent Changes, Current State, Known Issues, Current
Focus, Next Steps, Change History. Keep it concise. `context.md` is the only
`.agents/` file you may edit freely.
